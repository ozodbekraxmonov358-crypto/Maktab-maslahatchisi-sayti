1-USUL: GitHub Pages (bepul)

  2. Settings > Pages > Branch: main, / (root) > Save.
  3. Custom domain maydonida 8.maktabmaslahatchi.uz turganini tekshiring.
  4. Enforce HTTPS yoqing (DNS ulangach paydo bo'ladi).

  Papkani "Upload" qilib joylang, so'ng Custom domain bo'limida
